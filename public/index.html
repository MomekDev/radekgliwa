Płatności Stripe

Klienci płacą kartą, BLIK-iem lub Przelewy24 na stronie Stripe, a pieniądze trafiają na Twoje konto Stripe. Produkty i ceny AI zapisuje w pliku payments.json.

1. Klucz API

Skopiuj Secret key z dashboard.stripe.com → Developers → API keys. Zacznij od klucza testowego (sk_test_…), a gdy wszystko działa – wklej klucz sk_live_….

2. Webhook (zalecane)

W Stripe: Developers → Webhooks → Add endpoint. Wklej adres poniżej i wybierz zdarzenia checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed. Potem skopiuj Signing secret.

Własna domena

Podłącz domenę kupioną np. w OVH, home.pl, nazwa.pl lub Cloudflare. Po dodaniu ustaw u rejestratora rekordy DNS z tabeli i kliknij „Sprawdź”. Zmiany DNS mogą potrwać od kilku minut do kilku godzin. Certyfikat HTTPS wystawi się automatycznie.
